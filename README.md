# 🤖 Mami Bot — Issue Tracker & Support

Welcome to the official **Issue Tracker** for **Mami Bot** (Minecraft `1.20.1` – `26.3` Fabric).

> 📌 **Note:** This repository is used exclusively for **bug reports, feature requests, and user support** ([Issues](https://github.com/mami137/mamibot-issues/issues)).

---

## 🐛 Reporting a Bug / Sorun Bildirme
If you encounter any issues or bugs while using **Mami Bot**, please open a new issue on the [**Issues**](https://github.com/mami137/mamibot-issues/issues/new/choose) page and include:
1. **Minecraft Version** (e.g. `1.20.1`, `1.21.4`, `1.21.11`, `26.1.2`)
2. **Fabric Loader & Fabric API Version**
3. **Description of the issue** (and crash log / screenshot if applicable)

Herhangi bir hata veya öneriniz için üstteki [**Issues (Sorunlar)**](https://github.com/mami137/mamibot-issues/issues) sekmesinden **"New issue"** butonuna tıklayarak bildirim oluşturabilirsiniz.
